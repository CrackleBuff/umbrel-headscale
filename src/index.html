Connect a device

Official Tailscale apps work with Headscale. Point them at your server URL:

tailscale up --login-server https://YOUR-DOMAIN

On iOS/macOS/Android set a custom coordination server in the app settings. The device shows a register page with an ID; approve it on the Umbrel (Settings → Advanced → Terminal):

sudo docker exec cracklebuff-headscale_headscale_1 headscale users create alice
sudo docker exec cracklebuff-headscale_headscale_1 headscale auth register --user alice --auth-id <ID>

New tailnets deny all traffic until you add rules to the policy file. See the README.
